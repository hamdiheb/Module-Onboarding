Basic of Project Development Tools

A brief guide to README files, wireframes, and Git branches and their roles in project development.

What is the purpose of a README file?

A README file provides an overview of a project, explaining what it does, how to use it, and how to set it up. Its main purpose is to help others understand and use the project quickly.

What is the purpose of a wireframe?

A wireframe is a basic visual guide outlining a webpage or app’s layout and structure, used to plan design and user experience before adding visuals

What is a branch in Git?

A branch in Git is a separate line of development that allows you to work on changes independently without affecting the main project.
